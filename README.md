## Local preview
Open `index.html`, or run:
`python -m http.server 8000`

## Recommended deployment
1. Create a GitHub repository (for example `violeta-website`).
2. Upload all files from this folder to the repository root.
3. Connect the repository to Cloudflare Pages.
4. Build command: leave empty.
5. Output directory: `/` (repository root).
6. Cloudflare will provide a temporary `*.pages.dev` address.
7. Later connect your own `violeta.sa` or `.com` domain.
